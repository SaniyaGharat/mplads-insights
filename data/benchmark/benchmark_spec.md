---

## 1. Design Principles & Governance

1. **Episodes, not rows.** Each injection unit is an *episode* of 4–6 related works that together form a suspicious pattern. A single work from an episode may look normal in isolation.
2. **Three severity levels** per typology — *subtle*, *moderate*, *obvious* — controlled by parameter dispersion and deviation from normal distributions. 4 episodes per severity → 12 episodes per typology → 96 episodes total.
3. **Severity-stratified splits (50% Train / 25% Val / 25% Test)**:
   - For every typology × severity cell (4 episodes): 2 train / 1 val / 1 test.
   - Real-work pool (15 000 works): 50% train (7 500), 25% val (3 750), 25% test (3 750).
   - Zero episode leakage: each episode is strictly confined to one split.
4. **State Consistency**:
   - In the real dataset, 99.95% of works feature MP-IDA pairs belonging to the same state (state mismatch rate = 0.0467%).
   - Benchmark v2 enforces state consistency for 100% of injected works (MP home state == IDA state).
5. **Realism Constraints**:
   - **Amount granularity**: All injected amounts are rounded to whole rupees, matching real data where 99.53% of amounts are integers.
   - **Date boundaries**: For every injected work, `Recommended date = Sanction date - lag` strictly lies within the observed real data ranges:
     - `Recommended date` ∈ [2024-07-08, 2025-10-02]
     - `Sanction Date` ∈ [2024-07-09, 2026-09-04]
   - **Bounds**: amount ∈ [12 881, 46 470 400], lag ∈ [0, 732], `work_status_code` ∈ {0,1,2,3,4,5}, `work_category_code` ∈ {0,1,2,3}.
6. **Detectability Class (`detectability_class`)**:
   - **Tabular controls** (`B`, `C`, `E`): Defined by single-feature distributions (e.g. extreme lag, extreme amount, or threshold structuring).
   - **Structural typologies** (`A`, `D`, `F`, `G`, `H`): Single features are individually within normal distributions; detection requires graph / relational / sequence structure.

## 3. Typology Specifications

- **Detectability Class**: `structural`
- **Audit red flag**: Multiple MPs independently channel works to the same implementing agency within a narrow time window with suspiciously similar amounts.
- **State rule**: Pick an IDA in a state with $\ge 3$ MPs, then choose MPs from that same state.
